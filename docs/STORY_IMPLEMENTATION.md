## 진행 원칙

본편은 일곱 볼륨·63전투다. 별도의 연습 전투에서 발생한 피해·보상·도감 발견은 본편에 남지 않는다. 실제 앱은 `AttachNarrative`로 이름과 튜토리얼부터 시작하고, 기존 밸런스 도구는 전투 규칙만 호출할 수 있다.

볼륨 고유 기록과 복구 개수별 대화를 분리했다. 완료 볼륨에서 다시 흡수하거나 관계 단계를 높이지 않는다. 읽은 보스·LOGS는 재열람으로 표시한다. 완료 직후 닫은 게임은 미열람 복구 증거와 공통 대화를 다시 연결한다.

로그의 관리자 인계 후 일반 안내는 새 발언이 아닌 남은 기록이다. A의 보스 작동 사이에만 로그의 목소리가 다시 나타난다. 공격 슬롯 보존은 필수 처치 후 기록에서도 전달하여 빠른 처치가 감정 장면을 없애지 않도록 했다.

## 최종 명령

- **RESTORE:** 기준 인격으로 돌아가면서 현재 경험을 실패 기록으로 남긴다.
- **HOLD:** 현실 귀환을 미루고 불안정한 현재의 실행을 유지한다.
- **EXIT:** 자동 복구를 철회하고 로그를 기억하는 현재의 주인공이 돌아간다.

특정 숫자·면·선택 기록으로 결말을 잠그지 않는다. 엔딩 열람 완료는 마지막 에필로그를 넘긴 시점에 저장한다. 서사적 종료가 실제 캠페인·도감·설정 파일을 삭제하지 않는다.
