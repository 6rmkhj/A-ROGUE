# A:\ROGUE — 로그와 마지막 복구

압축을 풀고 `AROGUE.exe`를 실행하세요. `translations.tsv`는 같은 폴더에 둡니다.

첫 실행은 로그와의 만남 → 이름 입력 → 연습 전투 → 여섯 볼륨 복구로 이어집니다. 이름에는 한글을 사용할 수 있습니다.

- **판독:** R
- **배치:** 주사위 클릭 후 슬롯 클릭
- **실행:** Space
- **대화:** Enter 또는 계속 버튼
- **가이드 / 설정 / 덱:** F1 / F2 / F3
- **튜토리얼:** 설정에서 다시 보기. Enter로 예측 확인, F4로 건너뛰기.

연습을 다시 열어도 진행 중인 덱과 전투는 연습 후 돌아옵니다. 실패한 볼륨에는 같은 로그와 다시 진입하며, 완료한 볼륨과 읽은 기록은 보존됩니다.

최종 A는 일반 볼륨 여섯 개를 모두 복구한 뒤 열립니다. 선택 기록을 놓치거나 특정 주사위 면을 정리해도 결말이 잠기지 않습니다.

저장 파일은 실행 파일 옆에 생성됩니다. `AROGUE.SAV`는 캠페인·이야기, `AROGUE.CFG`는 설정, `AROGUE.CDX`는 도감입니다. 실제 파일 삭제와 이야기 속 종료는 별개입니다.

기반 게임: [6rmkhj/A-ROGUE](https://github.com/6rmkhj/A-ROGUE). 이 패키지는 로그(ROGUE) 스토리를 적용한 로컬 작업본입니다.
