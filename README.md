# A:\ROGUE — 로그와 마지막 복구

주사위 세 개로 손상된 볼륨을 복구하는 Win32/GDI 로그라이트입니다. 조력자 **로그(ROGUE)**와 여섯 볼륨을 복구한 뒤, 마지막 A에서 두 사람을 묶고 있는 종료 조건을 마주합니다.

기존 전투·디렉터리·덱·보스 기믹 위에 새 스토리와 튜토리얼을 구현한 작업본입니다. 게임 화면과 소리는 코드로 생성하며, 새 게임 진입에는 Higgsfield로 제작한 6.32초 무음 시네마틱을 함께 사용합니다. 시네마틱도 실행 파일에 포함되어 외부 엔진이나 별도 영상 플레이어가 필요하지 않습니다.

## 실행과 빌드

Windows에서 `build\AROGUE.exe`를 실행합니다. 한국어·영어 번역표 `translations.tsv`도 실행 파일 옆에 둡니다. Visual Studio의 **C++를 사용한 데스크톱 개발** 도구가 설치되어 있다면 다음 명령으로 게임과 검증 도구를 빌드합니다.

```bat
build-msvc.bat
```

MinGW 환경에서는 `build.bat`를 사용할 수 있습니다. 별도 화면·입력·오디오 검사는 다음과 같습니다.

```bat
tools\check-narrative.bat --render
tools\check-fx.bat --render
tools\check-audio.bat
tools\check-boot-film.bat
```

검토 프레임은 `build\narrative-qa\frames`와 `build\fx-qa\frames`에 생성됩니다. 생성물은 Git에 포함하지 않습니다.

새 게임 시네마틱 원본 프레임팩은 `assets/boot_intro.arvf`입니다. 빌드가 이를 RCDATA 201로 실행 파일에 포함하며, Windows 기본 WIC 디코더로 현재 프레임만 읽어 실제 창 배율의 고품질 확대 결과를 캐시합니다. 같은 프레임을 다시 그릴 때는 확대를 반복하지 않고, 창 크기가 바뀌면 캐시를 갱신합니다. FULL·REDUCED 모두 흔들림 없는 무음 영상을 사용하고 UI와 효과음은 게임의 시간에 맞춰 합성합니다. OFF는 연출을 즉시 건너뜁니다. 영상 준비에 실패하면 기존 코드 기반 연출이 실행되며, 재생 중 손상 프레임은 마지막 정상 프레임을 유지한 채 종료 화면으로 이어집니다.

ARVF v1은 little-endian 32비트 정수 헤더(`'ARVF'`, 버전, 가로, 세로, fps, 프레임 수), 각 프레임의 파일 시작 기준 바이트 오프셋·JPEG 바이트 길이 쌍, JPEG 데이터 순서입니다. 영상 프리뷰는 개발용이며 게임 배포에는 포함하지 않습니다.

Higgsfield 장면 원본·렌더 재생성 절차는 [시네마틱 제작 기록](assets/BOOT_INTRO.md)에 있습니다. `check-boot-film.bat`는 실제 내장 자산의 모든 프레임을 디코딩해 시간 경계·픽셀·재초기화·GDI 자원 보존을 검증합니다.

## 플레이 흐름

1. 화면 안으로 진입하고 로그가 이름을 묻습니다. 한글 입력을 지원하며 최대 16자입니다.
2. **R 판독 → 주사위 배치 → 예상 결과 확인 → Space 실행**을 실제 연습 전투에서 수행합니다.
3. C·D·E·N·R·X 중 제시된 볼륨을 선택합니다. 남은 볼륨이 세 개 이하이면 모두 보여줍니다.
4. 각 볼륨은 3층, 층마다 일반전 두 번과 보스전 한 번입니다. 일반전 앞에서는 하위 디렉터리를 고릅니다.
5. 보스 뒤 기록과 볼륨 복구 후 대화가 이어집니다. 로그와의 관계는 방문 순서 대신 서로 다른 볼륨의 복구 수에 따라 진행됩니다.
6. 여섯 검증이 모이면 통합 장면과 A가 열립니다. A의 세 보스는 로그의 인증·반사·마지막 실행입니다.
7. 최종전 후 **RESTORE / HOLD / EXIT**를 고릅니다. 특정 면이나 선택 기록이 필요한 결말은 없습니다.

실패해도 완료 볼륨, 이름, 관계 진행과 읽은 기록은 남습니다. 같은 로그와 사용자가 다시 연결됩니다. 완료 직후 게임을 닫아도 읽지 않은 핵심 기록을 다시 연결합니다.

## 조작

| 입력 | 동작 |
|---|---|
| R / 판독 버튼 | 현재 턴 주사위 확인 |
| 주사위 → 슬롯 클릭 | 배치·재배치 |
| 1 / 2 / 3 | 주사위 선택 |
| Space / 실행 버튼 | 배치 실행 |
| Tab / Shift+Tab, Enter | 전투·정리 항목 이동과 선택 |
| Esc | 선택 취소·주사위 배치 해제 |
| 스토리에서 클릭 / Enter / Space | 치던 대사 끝내기 → 다음 대사 → 다음 장면 |
| F1 / F2 / F3 | 가이드 / 설정 / 덱 |
| 설정의 연습 버튼 / 설정에서 T | 튜토리얼 다시 보기 |
| 튜토리얼에서 Enter / F4 | 예측 확인·연습 완료 / 건너뛰기 |

설정에서 연습을 열면 진행 중인 게임을 임시 보관합니다. 끝내거나 건너뛰면 덱·체력·판독 상태를 돌려받습니다. 훈련은 보상·도감·클리어 횟수를 올리지 않습니다.

## 구현 요소

- 주사위 3개 × 6면, 공격·방어·증폭·연쇄의 네 슬롯, 숫자·특수 면 설치와 용량 정리.
- 일반 볼륨 여섯 개와 최종 A. 첫 완주 기준 본편 63전투, 일반 적 21종과 보스 21종. 튜토리얼은 별도 연습입니다.
- 볼륨별 법칙과 보스 기믹, 정확한 발동 예고·피해 예측, 실제 계산에 맞춘 타격·봉인·역전 연출.
- 로그의 복구·침식 초상, 흡수·검사·정체 공개·관리자 인계 장면, 최종 인사와 결말별 연출.
- LOGS의 선택 기록 21편, 연속 대화 페이지, 재열람 표시와 이름 치환.
- 연출 FULL / REDUCED / OFF. 필수 대사와 전투 규칙 표시는 모든 모드에서 유지합니다.
- 절차적 음악·합성 효과음, 한국어·영어, 창 배율·전체화면과 독립 음량 설정.

## 저장과 문서

실행 파일 옆의 `AROGUE.SAV`는 캠페인과 이야기, `AROGUE.CFG`는 환경 설정, `AROGUE.CDX`는 적 도감을 독립적으로 보관합니다. 캠페인 v3은 72바이트의 명시적 인코딩과 체크섬을 사용합니다. v1/v2 진행을 보존해 이관하고 새 이야기의 소개와 미열람 기록을 제공합니다. 임시 파일 교체로 저장 실패 시 이전 파일을 보존합니다.

결말의 초기화·종료는 서사적 선택입니다. 실제 설정·도감 파일을 지우지 않습니다. 진행도 초기화는 설정에서 별도로 확인합니다.
