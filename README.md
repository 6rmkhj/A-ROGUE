# A:\ROGUE

1.44MB 게임 개발 공모전을 위한 Win32/GDI 로그라이트입니다. 외부 엔진, 이미지, 폰트 파일, 사운드 파일 없이 실행되며 그래픽과 효과음은 Windows API로 생성합니다.

## 구현 범위

- 3개 주사위 × 6면의 18면 덱
- 숫자 및 특수 면 8종
- 공격·방어·증폭·연쇄 슬롯
- 일반 드라이브 6종 + 최종 A: 드라이브마다 전용 일반 몹 3종 + 층별 보스 3종 (활성 42종, 레거시 11종 보존)
- 몹 특성 21종: 일반 적마다 전투 내내 참인 성질 하나. 대부분 굴린 눈의 홀짝·크기·직전 턴과 같은 눈인지를 보므로 눈의 값이 처음으로 크기 이상의 의미를 갖는다. 카드에 상시 표기되고 미리보기에 그대로 반영된다
- 고유 기믹 21종: 슬롯 잠금, 복원·되감기, 주사위 오프라인, 해결 순서 역전, 메모리 압력, 면 격리·영구 삭제 — 모두 발동 전 예고
- 기믹 발동 연출 21종 (기존 6개 계열 재사용): 예비 동작 → 히트스톱 임팩트 → 동작 → 여운의 골격을 공유하고, 사건이 난 자리에서 시작한다. 잠금은 보스 카드에서 신호가 내려와 층마다 다른 철문(마름모 격자 → 골판 → 단열 슬랫)이 칸을 덮고, 오프라인은 주사위 카드가 갈라지며 뽑히고, 경로는 슬롯 아래 배선과 사이드바 실행 순서가 갈렸다 재조립되며, 압력은 초상이 부풀고, 격리는 봉인 링이 조여든다. 프레임 스냅샷으로 잔상·데이터모싱을 내고 초상은 늘어났다 돌아온다. 전체 화면은 되돌릴 수 없는 `ZERO.DAY`와 판을 바꾸는 발동뿐 (BSOD는 전투당 한 번)
- 로스터 판독: 가이드 2페이지의 적·보스 6종이 헥스 노이즈로 덮여 있다가, 처치한 종류만 노이즈가 걷히며 정보가 열림 (런 단위)
- 42종 전용 + UNKNOWN 폴백의 16×16 코드 도트 초상 (총 54종)
- 3층 × 일반 전투 2회 + 보스전 (일반 몹은 시드 순서로 각 2회 등장)
- 층마다 두 번, 일반전 직전에 고르는 **하위 디렉터리 2택** (PROCESS · TEMP · CACHE · LOGS · INFECTED · CORRUPTED)
  - 노드는 면이나 상주 프로그램을 직접 주지 않고 다음 전투와 그 보상의 조건만 바꾼다
  - 위험·비용·보상 tier는 카드에 전부 공개되고, 가려지는 것은 아직 판독하지 않은 적 코드뿐이다
  - 드라이브마다 고정 가중치가 달라 같은 층이라도 볼륨별로 다른 선택지가 나온다
  - 경로 전용 난수열을 쓰므로 주사위·보상 난수 순서는 그대로다
  - 보스 앞에는 선택 화면이 없다 (고정 경로)
- 런마다 선택되는 디스크 손상 5종 중 2종
- 드라이브 카드 3장에 겹치지 않게 배정되는 볼륨 난이도 5등급 (초급자 25 · 중급자 50 · 전문가 75 · 악몽 100 · 광기 200 = 오염(관통) 피해 %)
- 관통 피해는 방어도를 절반만 인정 (막아낸 몫의 두 배가 방어도에서 소모)
- 보상 면 설치, 층간 용량 정리(삭제한 면 재클릭으로 복원), 승리·패배·재시작
- 실행 전 미리보기: 배치를 바꿀 때마다 슬롯별 예상 산출량과 `적 체력 -N · 내 체력 -M · 획득 방어도 B`를 표시 (판독 후에만, 읽기 오류가 있으면 흔들리는 값이 닿는 슬롯과 총합을 `?`로 가리고 확정 아님으로 표기)
- 턴 계산 재생: 현재 계산 줄은 적 카드와 슬롯 사이의 티커에, 최근 내역과 진행도는 오른쪽 패널에 표시되어 재생 중에도 전투판 전체가 보임
- 전투 연출: 규칙이 확정한 사건(증폭·공격·적중·방어·연쇄·화상·적 행동)을 계산 줄 번호와 함께 기록해 두고, 재생이 그 줄에 닿는 순간 신호 경로·충격·파편·체력 잔상·피해 숫자를 그 자리에서 재생 — 숫자를 읽지 않아도 작은 피해·큰 피해·처치가 구별됨
- 전투 리듬: 사건별 재생 간격, 강타 50ms·처치 85ms의 국소 히트스톱, 스프라이트 압축·반동, 방사형 스파크·충격파·처치 이중 폭발. 연쇄 신호는 적중 전에 이동하고, 피해 숫자는 같은 대상의 최신 적중만 보여 겹침을 줄임
- 증폭은 회전하며 모이는 에너지, 방어는 육각 방어막, 완전 방어는 넓은 방어막과 유리 공명음, 화상은 상승 불꽃으로 구분. 증폭·강타·방어 생성·완전 방어·연쇄에 전용 합성 효과음 5종 추가
- 드라이브별 색상과 회로·동심원·마름모 배경, 움직이는 데이터 패킷, 대상 조준 모서리, 슬롯 색상 연결, 주사위 판독 안착 파편. 일반전과 보스전 완료는 초록/금색 복구 파동으로 구분
- 계산 재생 중 실행 직전 주사위와 배치를 보존하고, 이미 발생한 사건만 누적 피해·적중 수·처치 수·방어 획득으로 집계. 클릭·Space·Enter로 건너뛸 수 있으며 생략한 공격 효과음을 한꺼번에 쏟아내지 않음
- 직접 조작 연출: 주사위를 배치·재배치하면 카드에서 슬롯으로 패킷이 이동하고 기존 연결과 밀려난 주사위가 함께 끊어진다. 보상 면·상주 프로그램·섹터 복구는 선택 카드에서 설치 위치까지 신호가 이어진 뒤 다음 화면으로 넘어가며, 용량 정리의 면 삭제·복원은 해당 칸에서 픽셀 분해·재조립된다
- 피격 연출: 계산 재생이 자기 행동 줄에 닿는 순간 적이 달려들고, 화면 흔들림·붉은 테두리·피해 표시가 함께 터짐
- 다수 적 전투: X:\ 2층 SANDBOX.BREACH가 3턴마다 검체를 탈주시킨다. 탈주체까지
  전부 쓰러뜨려야 전투가 끝나고, 보스를 먼저 끊으면 소환이 멈춘다. 적이 둘 이상이면
  연쇄는 대상이 아닌 쪽으로 튄다
- 연출 강도 설정 (FULL / REDUCED / OFF): 줄어드는 것은 흔들림·파편·전역 글리치뿐이고, 슬롯 잠금·오프라인 주사위·격리 대상 면·해결 순서·압력 게이지·체력 잔상과 피해 숫자는 모든 모드에서 유지
- 오디오 설정: Master / BGM / SFX를 각각 0~100%로 독립 조절하며 새 설정의 기본값은 모두 100%다. BGM on/off는 음악 재생 자체를 켜고 끄고, BGM 볼륨은 켜진 음악의 크기만 바꾼다. 모든 값은 `AROGUE.CFG`에 저장되어 재실행 후 유지된다.
- 설정의 언어 선택에서 한국어/영어를 즉시 전환. UI 번역은 실행 파일 옆의 `translations.tsv`에서 읽으므로 문구 수정에는 재빌드가 필요 없다
- 체력 10 이하부터 화면 가장자리가 무너지고, 체력 1에서는 버틸수록 그 띠가 두꺼워짐 (판 중앙은 유지)
- 체력 0이면 그 노이즈가 풀려나 화면을 가장자리부터 갉아먹고, 다 삼킨 뒤 재시작 화면으로 전환
- GDI 더블 버퍼링 UI, 코드로 그리는 도트 초상, 메모리에서 합성되는 효과음
- 드라이브별 VOLUME LAW, 보스/선택 LOGS 스토리, 여섯 볼륨을 모아 여는 최종 볼륨과 세 갈래 엔딩
- 외부 음원 없는 4채널 절차적 BGM과 전투 intensity·위독 편곡·SFX ducking

상세 규칙은 [RULEBOOK.md](RULEBOOK.md)를 참고하세요.

## 화면 전반 연출 개선 (2026-09-07)

연출은 준비 → 이동 → 접촉 → 안착의 순서로 구성합니다. 선택한 카드가 멈춘 뒤에도
계속 커졌다 작아지는 장식과 여러 화면에 반복되던 회전 고리·원근 격자를 걷어내고,
디스크·배선·읽기 헤드·복구할 파일에서 움직임이 시작되도록 정리했습니다.

- 타이틀은 플로피와 18면 섹터, 볼륨은 읽기 헤드가 있는 드라이브 랙, 디렉터리는 실제 선택 경로, 보상은 추출 버스, 스토리는 파일 이송 레일로 구분합니다. 정리 화면의 섹터 띠는 실제 사용 용량을 반영합니다.
- 카드는 시간차로 짧게 점등하고 선택 모서리는 자리를 잡고 멈춥니다. 설치 신호는 선택 카드에서 교체할 면·체력·상주 프로그램으로 모입니다. 글자와 클릭 영역은 고정되며 연출 때문에 입력을 추가로 잠그지 않습니다.
- 일반 공격은 가속과 짧은 발사 반동, 연쇄는 연결점이 이어지는 전기 궤적을 사용합니다. 강타 균열은 주 균열의 마디에서 갈라지고, 파편은 방향·항력·중력·회전을 갖습니다. 충격파는 비대칭이고 짧게 남습니다.
- 방어는 테두리 장갑이 맞물려 안착하며 중앙 글자를 가리지 않습니다. 보스 장갑은 평소에는 정지하고 위험한 의도를 낼 때 잠깐 조여듭니다. 전투 배선은 실제 배치한 주사위와 슬롯을 연결합니다.
- 체력 바는 공개된 피격 시점에만 줄어들며 손실 잔상을 남깁니다. 용량 바도 실제 사용량을 표시합니다. 보상·완료는 추출과 복구가 끝나는 자리에서 빛이 퍼지고, 엔딩은 기록의 정렬·해방, 패배는 신호가 가라앉는 여운을 사용합니다.
- 볼륨 선택의 파편은 카드 잠금장치에서 나오고, 마운트 읽기 헤드는 빠르게 이동한 뒤 정지합니다. 전체 화면을 덮던 진입 노이즈를 선택 카드와 레일에 모았습니다.
- 커서는 유효한 행동 위에서 170ms 머물렀을 때 한 번만 짧은 걸림음을 냅니다. 비활성 버튼은 무음이며 커서 소리가 BGM을 낮추거나 전투음을 끊지 않습니다. 보스·보상·복구는 각각 묵직한 잠금, 유리 공명, 부드러운 밀봉음으로 구분합니다.
- 모든 합성 효과음은 주파수 변화 중에도 위상을 이어가고 끝을 감쇠합니다. 별도 음원 파일 없이 기존 마스터 볼륨을 따릅니다.
- 새 장식은 FULL / REDUCED / OFF를 따릅니다. OFF 무효과, 실제 규칙으로 생성한 공격·연쇄·보상·UI 조작, 고정 시각의 픽셀 재현성, 게임 상태 불변, GDI 상태·객체 누수를 검사합니다.

`tools\check-fx.bat --render`로 한국어/영어·3개 강도·100%/200% 배율의 검토 프레임을
저장할 수 있습니다. `tools\check-audio.bat --export`는 33개 효과음의 8개 피치(264개 파형)를
무장치 상태에서 검사하고 새 효과음 4개를 WAV로 저장합니다. 파형 검사 2,563개에서
클리핑·버퍼 경계·마지막 진폭·결정성·DC 편향을 확인합니다. 두 검사 도구와 검토용 출력은
제출 패키지에 필요하지 않습니다.

현재 통합 검증은 5,476프레임(평균 7.59ms/프레임)에서 상태 변경·GDI 누수 없이 통과했습니다.
MSVC 빌드·스모크·밸런스·커브 및 격리 폴더의 Win32 시작 검사도 통과했고, 실행 파일과
번역표의 합계는 528,808바이트입니다.

## 보스 조우 연출 (2026-09-08)

디렉터리 화면은 구역마다 `LOCKED DESTINATION  ...\<BOSS>`를 띄워 두고도 정작 그
자리에 도착하는 장면이 없었습니다. 보스 구역에는 디렉터리 2택과 진입 연출이 둘 다
없어서, 두 번째 일반전의 보상을 고르면 적 카드 한 장이 조용히 갈리는 것으로 이 게임
에서 가장 큰 사건이 끝났습니다. 그 사이에 3.5초짜리 조우 연출을 넣었습니다.

- **경보 (0.68초)** 잠긴 목적지가 판독됩니다. `<BOSS>`로 가려져 있던 마지막 경로 조각이 헥스 잡음에서 왼쪽부터 실제 코드로 확정되고, 서명 불일치 경보가 올라옵니다.
- **게이트 (0.76초)** 그 경로를 막고 있던 철문의 봉인이 풀리고(짧은 진동과 파편) 두 문짝이 좌우로 갈라집니다. 갈라지는 이음매에서 불티가 튑니다.
- **강림 (0.86초)** 열린 틈 안쪽에서 보스가 앞으로 걸어 나옵니다. 어둠의 장막이 걷히고, 발이 바닥에 닿는 순간 충격파 두 겹·화면 흔들림·가장자리 섬광이 함께 터집니다.
- **명패 (0.80초)** 코드·이름·체력/피해/방어·위협도와 기믹 도장이 왼쪽에서 밀려들어와 박힙니다. 기믹 규칙과 대응 한 줄이 함께 서므로, 전투가 시작되기 전에 무엇을 조심해야 하는지 읽힙니다.
- **인계 (0.42초)** 명패가 위아래로 걷히면서 그 아래에 이미 그려져 있는 전투판이 가운데부터 드러납니다.

판은 연출이 시작되기 전에 이미 보스전 상태이므로(`StartCombat`이 먼저 끝나 있다)
어느 시점에 클릭이나 키로 건너뛰어도 결과가 같습니다. 모든 값이 경과 ms의 순수
함수라 마우스 이동 리페인트가 겹쳐도 같은 프레임이 나오고, 흔들림·파편·데이터 낙하·
바닥 격자 같은 장식은 연출 강도 FULL / REDUCED / OFF를 따릅니다. 잠금·게이트·명패의
수치는 어떤 강도에서도 숨기지 않습니다.

관리자 콘솔의 `boss` 명령으로 남은 일반전과 보상을 건너뛰고 지금 층의 보스 구역으로
바로 들어갈 수 있습니다. 층마다 한 번뿐인 이 연출과 기믹을 손으로 확인할 때 씁니다.

## 빌드

Visual Studio Build Tools와 `Desktop development with C++` 구성요소가 설치된 Windows에서 실행합니다.

```bat
build-msvc.bat
```

스크립트는 다음을 자동으로 수행합니다.

1. `vswhere`로 MSVC를 찾고 x64 환경을 설정
2. `rc`로 `src/arogue.rc`를 컴파일해 앱 아이콘을 리소스로 심음 (아이콘 `src/arogue.ico`는 `tools/gen_icon.py`가 도트 그림에서 생성 — 플로피가 드라이브 슬롯에 들어가는 순간)
3. `/MT`, `/utf-8`, 크기 최적화로 `build\AROGUE.exe` 생성
4. 결정론적 스모크 테스트: 로스터·초상화 무결성, 드라이브별 스폰 매트릭스, 18개 보스 기믹 시나리오, 디렉터리 생성·전이·노드 효과, 모든 손상 조합·6드라이브 전체 런
5. 드라이브별 300시드(총 1,800런) 휴리스틱 밸런스 검사 — 드라이브 승률 20~80%, 격차 30%p 이하, 모든 법칙 발동, 모든 난이도 승리, 모든 노드 제시를 검사
6. BGM 감상 도구 `build\wav.exe` 빌드 (실행은 하지 않음 — `build\wav.exe <폴더>`로 드라이브별 40초 WAV와 구조 로그를 뽑는다)
7. EXE의 정확한 바이트 수와 1,474,560B 대비 비율 출력 — 한도를 넘으면 빌드 실패

MinGW-w64가 이미 설치된 환경에서는 `build.bat`을 사용할 수 있습니다.

이펙트 전용 검증은 `tools\check-fx.bat`으로 실행합니다. 실제 화면 코드를 고정 시각의
오프스크린 버퍼에 그려 7개 드라이브 × FULL/REDUCED/OFF × 100%/200% 배율의 전투·판독·완료
장면을 검사합니다. 사건 시점, 히트스톱, 미래 피해 비노출, 실행 배치 보존, 게임 상태 불변과
워밍업 후 GDI 객체 수를 확인합니다. `tools\check-fx.bat --render`는 검토용 BMP를
`build\fx-qa\frames`에 추가로 저장합니다. 이 도구와 이미지는 제출 패키지에 필요하지 않습니다.

## 캠페인 진행 (1~7단계)

캠페인 개편 1단계로 저장 기반을 추가했습니다. 실행 시 실행 파일 옆 `AROGUE.SAV`를
읽고 볼륨의 마지막 보스를 처치한 직후와 정상 종료 시 저장합니다. 없는 파일·손상·지원하지 않는 버전은 새 캠페인으로 처리하며,
쓰기 실패는 플레이를 중단시키지 않습니다. 임시 파일을 쓴 뒤 교체하므로 저장 실패 시 기존
파일을 보존합니다. 스모크는 별도 임시 파일로 저장 왕복과 실패 처리를 검증합니다.

2단계에서는 저장된 클리어 볼륨을 후보에서 제외합니다. 미클리어 볼륨이 3개 이상이면
서로 다른 볼륨 3장, 1~2개면 그중 하나를 뽑아 서로 다른 난이도 3장을 제시합니다.
난이도는 계속 5등급 전체에서 추첨합니다.
진행도가 없는 런의 추첨과 난수 흐름은 기존과 동일합니다.

3단계에서는 마지막 보스 기록 → 볼륨별 원문 조각 → 챕터 클리어로 이어집니다.
`계속`으로 다음 볼륨을 선택하며, 사망하거나 다시 실행해도 완료한 볼륨은 남습니다.
이어하기 인트로와 클리어 화면은 복구된 문장을 볼륨별 고정 위치에 조립합니다.
4단계에서는 여섯 조각을 모으면 최종 `A:\ROGUE` 한 장이 열립니다. 전문가(오염 75%)로
마운트하며, 배드 섹터·읽기 오류와 최대 체력 +10을 적용합니다. 3층마다 SYSTEM VERIFY,
SNAPSHOT, PACKET CHAIN 법칙을 순서대로 재사용합니다. 신규 적 6종과 도트·BGM,
보스 기록·탐색 로그를 추가했습니다.

최종 보스들은 짝수 면 서명 검사, 직전 최고 슬롯 출력 복제, 피해로 지연하는 영구 슬롯
봉인을 사용합니다. 봉인 순서는 증폭 → 연쇄 → 방어이며 공격은 남습니다. 마지막 보스
처치 즉시 `finalCleared`를 저장합니다.

5단계에서는 최종 볼륨의 마지막 기록이 진실(`STORY_TRUTH`)을 열고 최종 명령 3지선다로
이어집니다. 일반 볼륨은 지금까지처럼 조각과 챕터 클리어로 끝나며 엔딩을 제시하지
않습니다. `RESTORE HOST`와 `EXEC ROGUE`에 여섯 조각을 모두 복구해야 도달하는
`MERGE SELF`가 더해졌고, 카드마다 보존되는 것과 닫히는 것을 함께 보여 줍니다. 고른
명령은 `AROGUE.SAV`의 `endingSeen`에 남아 다음 최종 명령 화면에 `기록됨`으로 표시됩니다.
중간 단계였던 `PHASE_CAMPAIGN_COMPLETE`는 사라지고 세 엔딩 모두 결과 화면으로 끝납니다.

6단계에서는 진행도를 화면에 드러냅니다. 타이틀·볼륨 선택·설정이 같은 여섯 칸 띠를 보여
주며, 볼륨 선택에서는 이번에 제시된 볼륨이 테두리로 구분됩니다. 진행도가 있으면 타이틀
버튼이 `이어하기`가 되고, 여섯 조각을 모으면 기록한 최종 명령 수까지 표시합니다. 설정에는
`진행도 초기화`가 추가되어 두 번 눌러 확정하면 세이브를 비우고 타이틀로 돌아갑니다.
`InitTitle`도 `NewRun`처럼 캠페인 스냅샷을 인자로 받으므로 화면과 세이브가 어긋날 수
없습니다.

7단계에서는 최종 볼륨의 난이도를 확정했습니다. 두 측정 도구가 최종 볼륨에도 일반 볼륨과
같은 구역별 표와 보스 도달·처치 내역을 출력하므로, 어느 구간에서 런이 끝나는지 숫자로
보고 조정했습니다. 밸런스에는 최종 볼륨 전용 게이트 세 가지가 생겼습니다 — 승률
15~40% 구간, 모든 일반 볼륨보다 낮은 승률, 세 보스 각각 최소 1회 처치입니다. 두 번째
게이트가 캠페인의 순서를 지킵니다.

조정한 값은 최종 볼륨에만 닿습니다. `SIGNATURE` 38/5/4 → 44/6/4, `SEVENTEENTH`
48/3/4 → 48/4/4, `LAST.WRITE` 68/7/6 → 74/8/6, 볼륨 특성 최대 체력 +6 → +10입니다.
체력 여유를 늘리고 보스를 함께 올려, 최종 층 잡몹이 아니라 보스가 벽이 되도록 했습니다.
기믹 매개변수와 여섯 일반 볼륨의 수치는 건드리지 않았습니다.

커브 도구도 스토리·디렉터리 전환과 챕터 클리어를 처리하도록 갱신했습니다.

7단계 검증: 스모크의 51개 전체 런과 저장·기믹 검사가 통과했습니다. 기존 6개 볼륨의
밸런스 1,051/1,800, 커브 901/1,800 결과는 3단계와 같습니다 — 조정이 일반 볼륨으로
새지 않았음을 이 두 숫자가 보장합니다. 최종 볼륨은 별도 300개 시드에서 밸런스 102회
(34%), 커브 95회(31.7%) 완주하며, 가장 어려운 일반 볼륨(E:\ 137회)보다 낮습니다.
사망의 64%가 보스전에서 발생합니다. FX QA는 7개 볼륨과 새 보스 연출, 최종 명령 화면과
세 엔딩 결과 화면, 타이틀·설정의 진행도 표시를 한국어·영어로 검사하고 3,168프레임에서
게임 상태 변경·GDI 누수 없이 통과했습니다.
MSVC 빌드는 앱과 검사 도구의 OBJ를 `build/obj` 아래로 분리해 덮어쓰기 충돌을 피합니다.

## 번역 수정

루트의 `translations.tsv`는 UTF-8 탭 구분 원본입니다. 한 줄에 `한국어 원문<TAB>영어 번역`을 적고, 실제 줄바꿈은 `\n`, 탭은 `\t`, 역슬래시는 `\\`로 표기합니다. `%d`, `%s`, `%c` 같은 서식 토큰은 양쪽에 같은 순서로 유지하면 실행 중 생성되는 체력·층·보스 문구에도 값이 자동 삽입됩니다. 두 빌드 스크립트가 이 파일을 실행 파일 옆으로 자동 복사합니다. 배포본의 `translations.tsv`를 직접 수정한 경우 설정에서 언어 버튼을 다시 누르면 재컴파일이나 재시작 없이 번역표를 다시 읽습니다.

## 제출 패키지

`build\AROGUE.exe`와 같은 폴더의 `build\translations.tsv`를 제출 패키지에 포함해야 합니다. PDB, OBJ, 스모크 테스트 실행 파일과 소스는 실행에 필요하지 않습니다. 빌드 스크립트는 두 실행 필수 파일의 합계가 공식 한도인 1,474,560바이트를 넘는지도 검사합니다.
# VOLUME LAW, 스토리, 절차적 BGM

각 드라이브는 기존 패시브와 별도로 전투 배치를 바꾸는 고유 `VOLUME LAW`를 가집니다.

- C `VERIFIED EXECUTION`: 가장 낮은 양수 기본 출력 하나 +1
- D `SNAPSHOT`: 직전 실행과 같은 die→slot 배치 하나 +2
- E `HOT SWAP`: 이미 배치한 주사위를 옮기면 턴당 한 번 전용 RNG 재굴림
- N `PACKET CHAIN`: CHAIN 외 유효 슬롯 둘 이상일 때 같은 연쇄 한 번 추가
- R `VOLATILE MEMORY`: 공격·증폭 기본 출력 +1, 적 행동 전 방어도 절반 휘발
- X `CONTRABAND`: 시작 압수 면 +2, 사용 뒤 다음 한 턴 격리

새 런은 끝이 찢긴 사용자 명령에서 시작합니다. 보스 기록과 선택형 `LOGS`를 복구하며
정식 복구 도구였던 A:가 왜 `ROGUE` 판정을 받았는지 추적합니다. 여섯 볼륨은 각각
정통성·기억·탈출·다른 사본·마지막 음성·책임이라는 서로 다른 증거를 보여 줍니다.
최종 원문을 복구한 뒤에는 무엇을 보존하고 무엇을 잃을지 확인하고 `RESTORE HOST`와
`EXEC ROGUE` 중 하나를 선택해야 승리 화면에 도달합니다.

음악은 외부 음원 없이 22.05kHz 모노로 실시간 합성됩니다. 여섯 드라이브의 BPM과
패턴, 전투 위험도, 보스 체력, 위독 상태, 스토리/엔딩에 반응하며 설정에서 BGM만 끌 수
있습니다. 기존 소리 슬라이더는 BGM과 효과음에 함께 적용되는 마스터 볼륨입니다.


### 되돌릴 수 없는 선택의 확정 규칙

- **보스 전리품:** 카드 선택 → 같은 카드 다시 입력해 설치 확정
- **디렉터리:** 첫 입력으로 후보 지정 → 같은 선택지를 다시 입력해 확정
- **최종 명령:** 카드 선택 → `Enter`/`Space` 또는 확정 동작으로 실행
- **보상 포기:** 현재 선택을 `Esc`로 먼저 취소하고, 선택이 없는 상태에서 `Esc`를 다시 입력해 포기 확정
